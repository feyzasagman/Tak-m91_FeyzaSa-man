## Bootcamp kontrol listesi (her sprint)

1. Backlog Dağıtma Mantığı  
2. Farklı günlerden Daily Scrum Notları (`<details>` ile)  
3. Farklı aşamalardan Sprint Board Updates  
4. Stable ürün durumu + ekran görüntüsü listesi (gerçek PNG manuel)  
5. Sprint Review (planlanan / tamamlanan / yetişmeyen / aktarılan)  
6. Sprint Retrospective + Action Items tablosu
