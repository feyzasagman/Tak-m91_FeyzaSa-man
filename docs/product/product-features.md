# Ürün Özellikleri — InternAI

Bu belge, geliştirilmiş ve sunuma hazır durumdaki özellikleri listeler. Yapılmamış özellikler “tamamlandı” olarak işaretlenmez.

## Kimlik ve erişim

- Firebase Authentication (e-posta / şifre)
- Kayıt, giriş, şifremi unuttum
- Korumalı platform rotaları
- Türkçe hata mesajları

## Dashboard

- Responsive kariyer kontrol paneli
- Özet istatistikler (CV/ATS, başvuru, mülakat, kabul, kaydedilen ilan)
- Hızlı işlemler
- Son CV analizi özeti
- Başvuru durum özeti
- Yaklaşan son başvuru tarihleri
- Son aktiviteler
- Yeni kullanıcı için başlangıç rehberi

## Staj ilanları

- Şehir bazlı staj ilanı listesi
- Arama
- Şehir, alan, çalışma modeli, staj türü filtreleri
- İlan detay sayfası
- İlan kaydetme
- Başvurulara ekleme
- Uyum skoru gösterimi

## CV analizi

- PDF yükleme (tür ve boyut kontrolü)
- PDF’den metin çıkarma
- Metin düzenleme
- CV bağlamını tarayıcıda saklama
- Beceri / bölüm tespiti
- Gemini ile CV–ilan uyum analizi
- ATS tahmini ve başvuru önerisi
- Analiz geçmişi (localStorage)
- Aşamalı süreç göstergesi

## AI Başvuru Asistanı

- Ön yazı oluşturma
- Başvuru e-postası
- CV iyileştirme önerileri
- Mülakat hazırlığı
- Kısa motivasyon metni
- İlan bağlamından form doldurma
- CV bağlamını forma aktarma
- Kopyalama, düzenleme, kaydetme, silme
- Üretim geçmişi
- Rate limit ve kullanıcı dostu hata mesajları

## Başvuru takip sistemi

- Başvurularım sayfası
- Liste ve Kanban görünümü
- Durum değiştirme
- Not ekleme / düzenleme / silme
- Timeline
- Mülakat / kabul / red bilgileri
- Filtreleme ve sıralama
- Verinin localStorage’da korunması

## AI Kariyer Koçu

- Öğrenilecek teknolojiler
- Güçlü alanlar
- Haftalık hedefler ve aksiyonlar
- Önerilen / riskli başvurular
- Başarı tahmini (kural tabanlı)
- Rozetler ve profil tamamlanma
- Günlük motivasyon kartı

## Profil / ayarlar (kısmi)

- Profil ve ayarlar sayfa iskeleti mevcuttur
- Ayarlar “Kaydet” kalıcı kayıt **tamamlanmamıştır** (disabled)

## Teknik / kalite

- Next.js App Router + TypeScript
- Feature-based mimari
- Koyu tema, responsive UI
- Ortak toast sistemi
- 404 ve error sınırları
- Gemini API anahtarının yalnızca sunucuda kullanımı

## Yapılmayan / ertelenen

- GitHub / LinkedIn profil analizi
- Firma / kariyer merkezi paneli
